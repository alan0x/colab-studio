🐚 MiniMax-H3（海螺 3 开源版 · 33B 音视频全模态）运行专区

硬件真相与避坑提示： MiniMax-H3 是 33B 参数的超大型音视频一体化模型（原生同步生成立体声 + 视频），原版权重超 65GB：
  • ❌ T4（16GB 显存）跑不动，会直接显存/内存溢出。
  • ⚠️ L4（24GB 显存 + 必须开启高 RAM）：可用 ComfyUI + Q4_K GGUF 量化勉强运行，但下载和推理较慢。
  • ✅ A100（40GB / 80GB + 高 RAM）：强烈推荐！搭配 ComfyUI + FP8 / GGUF 量化和 Google Drive 缓存体验最稳。
1

上传专用 Notebook 到 Colab

将项目 colab/Colab_MiniMax_H3_ComfyUI.ipynb 上传到 Google Colab。

2

选 A100（或 L4）并开启高 RAM

3

一键启动 ComfyUI 隧道

运行 Notebook 后，它会自动将 MiniMax-H3 量化权重缓存进你的 Google Drive，并输出一个 trycloudflare.com 地址。

提示：用完 MiniMax-H3 后，务必在 Colab Notebook 最后一个单元格点击“立即释放算力”，A100 费率约 6–10 单元/小时。

📘 3 分钟快速上手 + 省计算单元秘籍

第一步：启动云端显卡引擎

  1. 点击下方按钮在 Finder 打开 colab/ 文件夹，找到 Colab_Media_Studio_Server.ipynb。
  2. 访问 Google Colab → 文件 → 上传笔记本，选择该文件。
  3. 点击 代码执行程序 → 更改运行时类型：新手测试选 T4（最省，约 1.2 单元/小时）；日常出大片选 L4（约 2.2 单元/小时，命中率高）。
  4. 点击 全部运行，授权挂载 Google Drive（用于缓存模型和备份作品）。
  5. 大约 1–2 分钟后，Colab 底部会打印一行 一键连接码（格式：https://xxx.trycloudflare.com::你的密钥）。

第二步：在本地 App 粘贴连接码

  1. 点击右上角 连接设置，把 Colab 打印的一键连接码粘贴进去并点保存。
  2. 看到右上角变成绿灯并显示 GPU 型号（例如 Tesla T4 · 15GB）即可像用本地显卡一样生图、生视频！
  3. 所有生成的图片和视频都会自动下载到你电脑的 outputs/ 文件夹，并同步备份一份到 Google Drive。

💡 黄金省单元技巧（200 单元用出 500 单元效果）

  • 用完点右上角红色「释放算力」：这会远程执行 runtime.unassign() 彻底关闭 Colab 运行时，立刻停止扣费！千万别只关网页。
  • 先图后视频，低分辨率试水：先用 FLUX.1-schnell（4 步秒出图）挑出满意的画面，再一键转 图生视频（先用 25 帧 / 480p 试动效，满意再拉高帧数）。
  • 充分利用 Google One 缓存：开启 Drive 挂载后，每个模型只在第一次下载，之后重连秒加载，省下大量等待扣费时间。
  • 别死磕高峰期 A100：日常用 L4（24GB） 跑 Wan 2.2 5B 和 FLUX 性价比最高，200 单元可跑约 70–100 小时。
